# Portfolio SPA - Matrix Enterprises

## Overview

This is a Single Page Application (SPA) built with React for showcasing projects. It allows users to view, search, and add projects dynamically, as well as view detailed information for each project using client-side routing.

---

## Features

- Display list of projects on landing page
- Dynamic search functionality
- Controlled form to add new projects
- Project detail view using React Router
- Responsive layout
- Component-based architecture

---

## Technologies Used

- React
- React Router DOM
- JavaScript (ES6+)
- CSS

---
## How it works
### Home Page
 - Displays all projects
 - Includes search functionality
 - Allows adding new projects via form
### Adding Projects
 - Controlled form captures user input
 - New project is added to state dynamically
### Project Details Page
 - Clicking a project navigates to a detailed view
 - Uses React Router dynamic routing
